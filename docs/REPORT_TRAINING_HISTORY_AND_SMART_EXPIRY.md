# Formazione pregressa, crediti e scadenze suggerite

Data: 24/09/2026

## Principio
Il modulo è advisory-only:
- nessun credito viene assegnato automaticamente;
- nessuna scadenza suggerita sostituisce la data registrata;
- nessun progetto o attestato esistente viene modificato.

## Corsisti
Nuovo pannello Formazione pregressa / crediti:
- storico corsi SafetyManager in sola lettura;
- registrazione attestati/formazione esterna;
- ente emittente, numero attestato, data, ore, norma, evidenza;
- percorso/regola target facoltativa;
- valutazione manuale totale/parziale/non riconosciuta/da valutare;
- ore riconosciute, validità, motivazione e stato decisione.

## Scadenziario intelligente
Per ogni iscrizione:
1. usa la periodicità della regola normativa strutturata quando esiste una mappatura;
2. altrimenti usa la periodicità del catalogo SafetyManager;
3. mostra separatamente scadenza registrata e suggerita;
4. evidenzia allineamento o differenza;
5. se manca la scadenza registrata, il suggerimento può essere usato solo come promemoria per preparare il rinnovo.

## Compatibilità
Migrazione solo additiva. Conteggi di corsisti, iscrizioni, progetti e crediti verificati invariati prima/dopo.
