
# Step 14 - Chiusura corso, archivio imprese e PDF completo

## Punti implementati
1. Nelle stampe il logo CNA/timbro CNA compare solo se il soggetto formatore è l'ente/associazione CNA. Se il soggetto formatore è il datore di lavoro, le stampe mostrano i dati aziendali e non il logo CNA.
2. Nelle firme/stampe, per i corsi del datore di lavoro, il nominativo del firmatario finale viene ricondotto a referente formazione / responsabile progetto formativo.
3. La gestione iscritti viene aperta come finestra popup.
4. Aggiunta sezione `Archivio Imprese / Enti` con corsi e corsisti raggruppati per azienda e per ente erogatore.
5. Aggiunti campi di chiusura corso:
   - stato corso;
   - data chiusura;
   - link scansioni documenti firmati;
   - note chiusura.
6. Nel Centro Stampe aggiunto comando `PDF unico progetto + attestati`, che prepara tutte le stampe del progetto e apre il dialogo di stampa per salvare in PDF sul PC.

## Nota operativa PDF
Il browser non può salvare automaticamente un PDF senza conferma utente. Il comando prepara il fascicolo completo e apre la stampa; scegliere `Salva come PDF` per salvare sul PC.
