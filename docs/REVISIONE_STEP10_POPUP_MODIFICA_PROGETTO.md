
# Step 10 - Modifica progetto tramite popup da Codice ID

## Modifica introdotta
Il Codice ID nella tabella `Progetti Attivi` è ora cliccabile.

Cliccando sul codice:
- viene aperta una finestra popup;
- viene caricato direttamente il progetto selezionato;
- il form di Gestione Progetto viene utilizzato come editor completo;
- al salvataggio il popup si chiude e la tabella viene aggiornata.

Anche gli alert della Dashboard usano la stessa apertura in popup, così non è più necessario cercare manualmente il progetto.
