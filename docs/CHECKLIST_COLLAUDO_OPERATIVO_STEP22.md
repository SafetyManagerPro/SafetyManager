
# Checklist collaudo operativo

## Progetti
- Creare un progetto nuovo.
- Modificare un progetto da `Progetti Attivi`.
- Verificare scroll autonomo di `Gestione Progetto`.
- Aggiungere corsista esistente.
- Creare nuovo corsista e iscriverlo.
- Modificare corsista inline.
- Rimuovere corsista dal corso.
- Usare `Di più / Mostra meno`.
- Impostare stato `svolto`.
- Impostare stato `chiuso` con link documenti firmati.
- Verificare badge errori/verified.

## Stampe
- Progetto formativo.
- Registro.
- Verbale.
- Fascicolo.
- Attestato fronte/retro.
- PDF unico progetto + attestati.

## Export
- Aziende XLSX/PDF.
- Corsisti XLSX/PDF.
- Docenti XLSX/PDF.
- Progetti XLSX/PDF.
- Archivio XLSX/PDF.
- Scadenze XLSX/PDF.

## Backup
- Scaricare backup locale.
- Analizzare backup.
- Ripristinare backup su ambiente di test.

## Responsive
- Desktop grande.
- Desktop piccolo.
- Tablet orizzontale.
- Tablet verticale.
- Smartphone verticale.
- Smartphone orizzontale.

## Browser consigliati per collaudo
- Chrome/Edge desktop.
- Safari macOS per stampe.
- Safari iPad/iPhone per layout.
- Chrome Android.
