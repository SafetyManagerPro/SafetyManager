Data Import Wizard

Migrazione avanzata da file CSV o JSON con mappatura, simulazione preventiva e controllo duplicati

Backup locale database

Esporta su PC una copia locale in formato ZIP/JSON delle tabelle principali di Supabase. Il backup non modifica il database ed è utile prima di migration, importazioni o aggiornamenti.

Ripristino backup database

Importa un backup locale generato da SafetyManager. Il ripristino è conservativo: aggiorna/inserisce i record presenti nel file, senza cancellare automaticamente i dati esistenti non presenti nel backup.

Consigliato: esegui prima un nuovo backup locale.

1. Seleziona il file sorgente

Formati supportati: .CSV con separatore automatico e .JSON come array di oggetti.

2. Mappatura colonne dati

Il sistema ha tentato di associare automaticamente le colonne del file ai campi del database. Controlla e correggi eventuali errori tramite i menu a tendina.

3. Simulazione prima dell'import

Prima di scrivere sul database, controlla duplicati, campi mancanti e azioni previste.
